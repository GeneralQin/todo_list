# 日序

一个用 React 和 Vite 构建的个人待办提醒工具。支持新增、编辑、删除和勾选待办，以及按时间查看提醒。

## 本地运行

在项目目录打开 PowerShell。

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173`。已有依赖时可以直接启动。

## 提醒与保存

- 「全部待办」每页显示 3 项。超过一页时，支持自动轮播、暂停和手动翻页。查看或编辑待办时会暂缓自动翻页。
- 首次使用会显示 9 条示例待办。已有清单可以点击「添加示例」，原有待办会保留。
- 给待办设置提醒时间，到点时网页会显示提示。点击「开启通知」并授予权限后，支持的浏览器还可以显示桌面通知。
- 请保持页面打开以接收提醒。若页面关闭或浏览器暂停了计时，重新打开或返回页面时会检查尚未提示的到期待办。
- 数据保存在当前浏览器的本地存储中。同一浏览器使用同一地址时，刷新后可以继续使用。

运行 `npm.cmd run build` 可以生成 `dist/` 静态文件。
